# AI Desktop Controller

A powerful Node.js application that allows an AI to control your desktop computer through a web interface. The AI can see your screen, control mouse and keyboard, execute commands, and interact with applications - all with built-in confirmation prompts for security.

## Features

- 🖥️ **Real-time Screen Capture**: AI can see your desktop through screenshots
- 🖱️ **Mouse & Keyboard Control**: Complete input device automation
- 💬 **Voice & Text Communication**: Talk to the AI or type commands
- 🔒 **Confirmation Mode**: All terminal commands require user approval
- 🌐 **Web Interface**: Modern, responsive web client
- ⚡ **Real-time Communication**: WebSocket-based instant updates
- 🎯 **Smart AI Integration**: Context-aware desktop assistance
